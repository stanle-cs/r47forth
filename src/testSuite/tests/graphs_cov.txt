; clearScreenOld does NOT clear the register-line (left) text panel between two
; consecutive plot programs, so a plot with a full panel (ASSESS or HISTO) leaves
; text a following plot does not overwrite. A SCATR *after a stat plot* (PLSTAT /
; SCATR / ASSESS) renders an empty panel, so each rich-text plot below is preceded
; by such a SCATR and renders identically to its standalone capture. HISTO is the
; exception - it contaminates a following SCATR too - so HISTO must run last. That
; leaves plotStatMx = "HISTO" at exit, which is benign: fnClSigma below clears
; drawHistogram and the rest of the plot state, and every fnPlotStat resets
; plotStatMx at entry, so no later plot or test can be affected by it.
; DO NOT reorder HISTO before ASSESS: SCATR does not reset the panel after HISTO.
