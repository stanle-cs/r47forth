# Design documents

Specifications, plans, audits, prompts and historical notes live here, grouped
by product package or shared subsystem.

`design-docs/forth-core/DESIGN.md` is the authority for forth-core behavior.
The source working area remains under `packages/forth-core/`.

`design-docs/package-manager/` contains the shared package-overlay
specification, implementation history, audits, operational notes and tooling
prompts. It applies to every package rather than to forth-core behavior.
